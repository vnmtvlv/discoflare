# Discoflare 0.1.5

## Agents and Tasks

- Agents are deliberately focused on the current collaboration loop: they reply in workspace chats and can list, read, and create Tasks.
- Assigning a Task to an Agent records ownership. It no longer starts autonomous execution.
- Agent Computer, shell and filesystem tools, Task Runs, Workflows, and Container bindings have been removed. Agent chat and task access no longer depend on those paid execution resources.
- The experimental Worker PR Preview workflow has been removed for now. Preview environments will be designed and tested separately instead of being part of this release.

## Fixes

- The chat header no longer shows "Connecting" or "Reconnecting" text. The live connection only carries new events, so it now stays silent while it connects normally, shows a thin progress line under the header if reconnecting takes more than a few seconds, and a quiet offline icon with an explanation when the device has no connection.

- Opening a settings link such as `?section=email` on a phone now opens that section instead of the section list.
- In **Email → Domains**, a domain that still has mailboxes shows "In use" with an explanation instead of a Disconnect button that does nothing, and the zone name only appears when it differs from the domain.
- Adding an email domain that is already connected is caught before submitting, and the domain field is focused when the dialog opens.

## Deployment

- Migration `0026_retire_task_execution.sql` restores Tasks left in `running` to their previous state (or a safe backlog/ready fallback), cancels queued or running historical Task Runs, and keeps their records for history.
- The Worker no longer declares Workflow or Container bindings and no longer packages `@cloudflare/computer`.
- Existing managed workspaces can update from **Workspace Settings → System → Updates**.
