# Discoflare 0.1.2

This release makes the workspace faster and calmer to use, especially on phones and far from the D1 region.

## What's new

- Pages load much faster. Each request resolves the signed-in member once, runs independent permission checks together, and no longer repeats schema checks or mail bootstrap writes on every page load. The sandbox Worker also enables Smart Placement so it runs near its D1 database.
- Workspace Settings are grouped into Workspace, Features, Access, and Installation. **Cloudflare** now holds Overview, Domains, Backups, Updates, Telemetry, and Delete as tabs, and older settings links still open the right tab.
- **Roles** is a searchable list that opens into a role with Display, Permissions, and Members tabs. Permissions are grouped, members can be added or removed in place, and unsaved edits show a save bar.
- **Email** separates Mailboxes and Domains. Each mailbox opens into its own view with a searchable access list.
- On phones every page (Tasks, Data, Apps, Docs, Canvases, Mail) has the navigation button, the navigation drawer is wider, dims the page behind it, and opens and closes with a swipe.
- Tabs across the app share one segmented style.

## Fixes

- Loading shows content-shaped placeholders instead of gray blocks and "Opening…" text. The chat header, composer, and connection badge no longer show misleading states while a channel loads.
- Failed loads show a quiet message with **Try again** instead of a solid red alert, and alerts use the tinted style throughout.
- Opening a settings link such as `?section=roles` no longer falls back to Overview while permissions load.
- Disconnecting an App Domain or Email Domain now asks for confirmation.
- Error messages no longer overflow the screen on phones.

## Deployment

- There are no database migrations in this release.
- Existing managed workspaces can update normally from **Workspace Settings → Cloudflare → Updates**.
- Repository deployments should keep `"placement": { "mode": "smart" }` in `wrangler.jsonc`.
