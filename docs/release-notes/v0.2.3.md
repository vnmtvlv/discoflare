# Discoflare 0.2.3

Choose who a new workspace is for directly in Discoflare Admin.

## Workspace owner selection

- **This workspace is for me** is selected by default. The form shows your signed-in Admin email as read-only, and uses it for the workspace owner setup.
- Uncheck it to enter another owner's email. Create the workspace, then share its private setup link with that person. No setup email is sent automatically.
- The form requires a valid owner email. The server validates the choice before provisioning and derives the email from the authenticated Admin session when creating a workspace for yourself.
- Switching between the two choices preserves the other owner's email while the form is open. Opening a new creation form restores the default choice.

Admin claim and workspace owner setup remain separate. This change does not reuse the Admin password, automatically sign you into the workspace, or merge the two accounts.

## Updating

Update your account-local Admin to 0.2.3 to get the new creation form. Existing workspaces need no changes for this feature, and older creation clients keep using the signed-in Admin owner's email by default.

No new D1 migrations, Cloudflare bindings, or permissions are required. The release includes matching workspace, Admin, and admin-core artifacts.
