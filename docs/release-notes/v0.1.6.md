# Discoflare 0.1.6

A pass over the whole frontend: phones get the full chat, pages open faster, and the workspace stays live wherever you are.

## What's new

- **Threads in the navigation.** Recently active threads appear under their channel, like Discord. A thread you have opened shows its unread replies live, and opening one highlights its channel.
- **Message actions on phones.** Long-press a message for quick reactions, Reply, Start or open a thread, Pin, Copy text, Edit, and Delete. Before, these were only reachable by hovering with a mouse.
- **Apps.** Gadgets are now called Apps everywhere you read them: the empty state, dialogs, messages, and the Use apps / Manage apps permissions.
- **Empty pages explain themselves.** Tasks, Data, Apps, Mail, and the Threads, Pins, and Files panels say what they are for and offer the first step. Admins without a mailbox get a direct way to set up email.
- **Mute and deafen are real settings.** They carry into your next call, the pre-join dialog starts from your mute setting, deafen also silences people who join later, and undeafening restores your microphone.
- **Richer messages.** Bulleted and numbered lists render, and links and inline code are styled.

## Fixes

- Your own status no longer shows Offline outside Chat, and unread dots, presence, and incoming call alerts keep updating on Tasks, Mail, Data, and Apps.
- Chat reopens your last channel. The last channel was saved incorrectly and never remembered, so every visit waited for the full channel list.
- The navigation renders with the page instead of appearing a moment later, and messages start loading about five seconds sooner on a fresh visit.
- Phones get the phone layout on first paint instead of the desktop layout.
- Deleting a message asks for confirmation. It used to delete immediately, and on phones an invisible toolbar button could be tapped by accident.
- Opening a thread from the navigation works from any channel, including the one it belongs to, and Back returns to that channel.
- The app switcher, workspace name, archive links, and thread titles show placeholders while loading instead of `…`, a partial set of apps, or "Thread".
- Header actions such as + Task and + Record stay hidden until there is a board or database to act on.
- The user panel's profile button has a rounded hover, and the Threads panel keeps each summary on one line.

## Deployment

- There are no database migrations in this release.
- The Worker compatibility date moves to 2026-09-28, and the release no longer lists `nodejs_compat` as an explicit flag. Guided installations pick this up automatically on update.
- Existing managed workspaces can update from **Workspace Settings → System → Updates**.
- Repository deployments that build from source need Node.js 24, as pinned in `.node-version`.

## Known limitations

- Mute, deafen, and huddles require RealtimeKit to be connected under **Workspace Settings → Live**.
- Threads appear in the navigation for seven days after their last message; older threads stay in the channel's Threads panel.
