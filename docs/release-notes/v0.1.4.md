# Discoflare 0.1.4

Settings follow where people look for things.

## What's new

- Add and disconnect email domains from **Workspace Settings → Email → Domains**, next to the mailboxes that use them. With no domain yet, Email opens there instead of pointing somewhere else. Only the owner can change domains; admins see the list.
- **Cloudflare** in Workspace Settings is now **System**, with Overview, Domain, Backups, Updates, Telemetry, and Delete tabs. **Domain** holds the workspace's custom address.
- Domain fields read as `name . zone` with a concrete example underneath, such as the address format a new email domain will use.

## Fixes

- Dialog actions are aligned to the right in every dialog.
- Dialog backdrops dim the page instead of lightening it in dark mode.
- Disconnecting an email domain that still has mailboxes is disabled with an explanation, instead of failing after confirmation.

## Deployment

- There are no database migrations in this release.
- Existing managed workspaces can update from **Workspace Settings → System → Updates**.
