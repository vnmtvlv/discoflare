# Discoflare 0.1.7

Chat that behaves the way Discord users expect, tasks that people can own and talk about, a database table you can work in, and your own avatar.

## What's new

- **Your own avatar.** Upload, replace, or remove a profile picture from **User Settings → Profile** by clicking or dropping an image. It is cropped to a square in the browser, GIFs stay animated, and it appears on your messages, in the member list, DMs, huddles, and settings. The Profile page also gains a display-name counter, a Reset button, and a preview of how you appear in chat.
- **Edit messages in place.** Editing happens inside the message: Enter saves, Esc cancels, and emptying it offers to delete. Your draft and pending reply in the composer are left alone. Press ↑ in an empty composer, or E on a focused message, to edit.
- **A better composer.** `@member` and `:emoji:` autocomplete (including names with spaces), paste or drop files, a "Replying to" bar, a counter near the 2,000-character limit, a 10 MB check before upload, and typing anywhere focuses the composer.
- **Reactions and message actions.** An emoji picker with search and recent emoji, a More menu and a right-click menu to copy text, link, or ID, hold Shift to pin or delete without confirmation, and keyboard shortcuts on a focused message (E, R, T, P, Delete).
- **Richer messages.** Strikethrough, underline, spoilers, headings, subtext, `>>>` block quotes, and language labels on code blocks. Mentions of you and replies to you are highlighted, emoji-only messages show large, and clicking a name or avatar opens a profile card.
- **Navigating history.** The list stays at the bottom while images load, **Jump to present** shows how many new messages are waiting, older history loads as you scroll up, and message links jump to and highlight the message.
- **Assign tasks to people.** Tasks could only be assigned to Agents. The assignee picker now lists People and Agents, and cards show the assignee's avatar and name.
- **Task Discussion.** Each task can have its own conversation, created the first time someone opens it. It supports messages, reactions, replies, and files, and only members who can manage tasks can see it.
- **A workable database table.** Type into the **New record** row at the bottom of a table and press Enter to add a record; the field keeps focus so you can keep typing. Resize columns by dragging the header edge or with the arrow keys; widths are saved per view. A record added in a filtered view starts with values that match simple filters and stays in place until you leave the view.

## Fixes

- Messages sent while your connection was reconnecting no longer go missing.
- Messages sent in quick succession are stored in the order they were sent. They could previously arrive out of order.
- Masked links no longer render as broken links, `&` in URLs is no longer mangled, `snake_case_names` are no longer turned italic, and formatting no longer applies inside inline code.
- Editing a database cell no longer reloads the whole database. Renaming a record used to take several seconds and could fail with a conflict; a genuine conflict now reloads that record and applies your edit once.
- Create board and create task dialogs close as soon as the server confirms, and the new item appears immediately. Enter in the task title creates the task.
- In the task panel, Depends on only appears when there are other tasks, files attach as soon as they are chosen, and Archive and Delete sit at the bottom.
- Chat feels faster: hovering a channel, thread, or DM preloads its messages, attachments upload in parallel, and each message renders fewer hidden controls.

## Deployment

- This release adds database migration `0027_task_people_and_discussions`. Guided installations and `pnpm deploy` apply it automatically. It moves existing task assignments to a new column that can hold people as well as Agents.
- **Downgrading is not supported.** After this migration, version 0.1.6 no longer sees task assignees. If you must roll back, restore a backup taken before updating.
- There are no new Cloudflare bindings or permissions. Avatars use the existing file storage bucket.
- Existing managed workspaces can update from **Workspace Settings → System → Updates**.
- Repository deployments that build from source need Node.js 24, as pinned in `.node-version`.

## Known limitations

- Avatars from social sign-in providers are not shown; upload a picture from your profile instead.
- Task Discussions do not support threads.
