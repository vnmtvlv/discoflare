# Discoflare 0.1.3

A small follow-up to 0.1.2.

## Fixes

- The channel name no longer disappears from the chat header when the navigation and right panel leave the conversation column narrow. The header adapts to its own width, and search collapses to an icon when space is tight (phones now get a search button too).
- **Workspace Settings → Cloudflare → Domains** opens without waiting: the domain list starts loading in the background from the Overview tab and is reused for a few minutes.
- Email Domains on the Cloudflare Overview wrap instead of being cut off.

## Deployment

- There are no database migrations in this release.
- Existing managed workspaces can update from **Workspace Settings → Cloudflare → Updates**.
