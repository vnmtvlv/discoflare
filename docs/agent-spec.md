# Discoflare agent spec

The originating product spec is the attached `DISCOFLARE_AGENT_SPEC.md` from the repo bootstrap. Implementation follows that document: Nuxt 4 on Workers, D1 catalog, Channel/workspace-presence/RateLimit Durable Objects, R2 attachments, KV WebSocket tickets, RealtimeKit huddles, MIT license.

v0.1 includes one workspace, public/private text and voice channels, Direct Messages (1:1 and group), threads, reactions, and RealtimeKit huddles on voice channels and DMs.

Out of v0.1: forums, bots, full-text search, SSO, email sending, mobile apps.
