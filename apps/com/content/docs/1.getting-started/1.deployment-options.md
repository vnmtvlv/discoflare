Discoflare has one supported production runtime: Cloudflare Workers with D1, R2, KV, Durable Objects, Workflows, Workers AI, and Containers. Choose how you want to provision that runtime.

## Guided installer

Choose [discoflare.com/deploy](/deploy) to bootstrap one Discoflare Admin Worker in your Cloudflare account. Admin then provisions and operates all guided workspace Installations.

| Capability | Runtime |
| --- | --- |
| Web application and API | Workers |
| Durable workspace data | D1 |
| Attachments and recorded audio | R2 |
| Live rooms, presence, and coordination | Durable Objects |
| Short-lived connection tickets | KV |
| Agent inference | Workers AI |
| Durable Agent runs | Workflows |
| Durable Agent filesystem | Durable Object SQLite |
| Agent command execution | Containers |

Managed Setup uses public-client PKCE OAuth to create or repair `discoflare-admin` and create its fixed Account Admin Token as an encrypted Worker secret. Discoflare.com then discards the temporary grant. Later Admin sign-ins use the same OAuth client for identity only. Workspace Workers receive no broad credential; Admin provisions their bindings, storage, migrations, Huddles, eligible email, and public URLs.

Choose [Private Setup](/deploy/private) to bootstrap the same Admin without creating an account token. The temporary installer relinquishes access, and the operator pastes one Account Admin Token directly into Admin.

The standalone CLI shipped with every GitHub Release uses the same installer core and reads release artifacts directly from GitHub. It is the recovery and automation path when `discoflare.com` is unavailable; set an appropriately scoped `CLOUDFLARE_API_TOKEN`, then use `discoflare inspect`, `install`, or `update`. The website is required only to start the OAuth-guided path, not to keep an installed workspace running.

**Requirements:** a Cloudflare account and the Workers Paid plan for Agent Containers. An active zone is optional unless you select a custom domain or workspace mail.

## GitHub / Workers Builds

Choose the repository-based method when you want to own a fork and the Workers Builds configuration.

This is a manual deployment method. The GitHub button hands the source repository to Cloudflare; it does not perform the Discoflare installer's account setup. You must create or select the D1, R2, and KV resources, adapt the Wrangler configuration, configure every required binding and secret, set the build and deploy commands, attach the hostname, configure optional email and OAuth services, run migrations, and verify the Worker yourself.

The result is the same complete Cloudflare runtime when all of those steps are configured correctly. The difference is who performs and verifies provisioning.

**Requirements:** a Cloudflare Workers Paid account, an accessible GitHub fork or repository, Workers Builds, and comfort managing Cloudflare resources and secrets manually.

## Responsibility comparison

| | Guided installer | GitHub / Workers Builds |
| --- | --- | --- |
| Runtime | Cloudflare | Cloudflare |
| Source repository required | No | Yes |
| Resource provisioning | Discoflare Admin | You |
| Bindings and secrets | Discoflare Admin | You |
| Sign-in | Discoflare accounts by default; Access optional | You |
| Custom hostname | Optional, Discoflare Admin | You |
| Workspace mail routing | Eligible Primary Installation, Discoflare Admin | You |
| Migrations and readiness checks | Discoflare Admin plus operator verification | You |

::docs-verification{title="The GitHub button is not the guided installer"}
A successful repository connection or Workers Builds run proves only that source reached Cloudflare. Record the resource IDs, bindings, secrets, migration result, Worker version, hostname, health response, owner setup, and browser checks before calling a manual installation complete.
::

## Repository visibility

The guided Cloudflare installer is served by `discoflare.com`; it does not require this marketing-site repository to be public. The alternative Cloudflare Deploy Button builds from the public, MIT-licensed [Discoflare application repository](https://github.com/vnmtvlv/discoflare).

Only the repository selected as a build source needs to be accessible to that platform. Publishing rendered documentation does not publish this website's private repository, server code, or environment values.
