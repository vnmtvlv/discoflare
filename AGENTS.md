# Discoflare

Self-hosted team chat on a user's Cloudflare account. Spec for this repo lives in `docs/agent-spec.md`.

Stack: Nuxt 4, Pinia, TanStack Query, D1 + Drizzle, Durable Objects (Channel / Workspace / RateLimit), R2, KV, RealtimeKit huddles.

Do not add DMs, bots, Nitro, Discord branding, or extra products. Ship the v0.1 surface in the spec.
